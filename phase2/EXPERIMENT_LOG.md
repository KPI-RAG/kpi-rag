# EXPERIMENT_LOG — KPI-RAG Phase 2 (Data & Models)

All experiments: Raneem's session split (28 training sessions / 5 held-out test sessions {1,3,4,13,17}),
StratifiedGroupKFold by session, 5 folds × 5 seeds unless stated; Nadeau-Bengio corrected paired t-test
(Wilcoxon as check); test set used once per step, post-hoc, never for selection.
Decision rule (2026-10-13): a change replaces the current pipeline only if corrected p < 0.05 AND
≥ 0.03 macro-F1 (or a material cascade gain) AND it holds on the held-out sessions.
